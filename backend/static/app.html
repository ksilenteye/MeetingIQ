Help & Support

Install steps, and what to check when nothing shows up.

Install the extension

  1. Download the zip — it is already pointed at this server.
  2. Extract it. On Windows, right-click → Extract All.
  3. Open chrome://extensions, enable Developer mode.
  4. Load unpacked → pick the folder containing manifest.json.
  5. Join a Meet and turn on live captions (CC).

Nothing appearing?

  • Captions must be on in Meet — nothing is captured without them.
  • A ! badge on the extension icon means POSTs are failing. Check the server is up.
  • Pick the right meeting from the dropdown; the view is per-meeting.
  • Summaries need an API key, or the heuristic fallback enabled in Settings.
