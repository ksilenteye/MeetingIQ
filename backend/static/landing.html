How It Works

Four moving parts, all of them yours.

1 · Capture

The extension watches Google Meet's live-caption box and sends only what is new.

2 · Store

Captions land in SQLite and broadcast to every open dashboard in real time.

3 · Index

Text is chunked and embedded into a local vector index for retrieval.

4 · Answer

Ask anything. Summaries and answers are grounded in the retrieved transcript.

How to Install the Extension

Get started in less than 2 minutes.

  1. Download the extension It is built on demand and already wired to this server — nothing to configure.
  2. Extract the zip On Windows: right-click → Extract All. Don't load it from the zip preview window.
  3. Enable Developer mode Open chrome://extensions and turn on Developer mode (top right).
  4. Load unpacked Pick the extracted folder — the one containing manifest.json. The 🎙️ icon appears in your toolbar.
  5. Start a meeting Join any Google Meet and turn on live captions (the CC button). Nothing is captured without them.

About the Project

What MeetingIQ is, and what it isn't.

MeetingIQ is a self-hosted meeting assistant. A Chrome extension scrapes Google Meet's live captions, a FastAPI backend stores them in SQLite and streams them to your dashboard, and a local RAG pipeline embeds the transcript so summaries and answers are grounded in what was actually said. Everything runs on the machine you deploy it to — there is no third-party transcript store, and API keys stay in your browser.
